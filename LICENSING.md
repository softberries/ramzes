## What the AGPL means for you

You can use, modify and run ramzes freely, including in production. Services that send events to ramzes over HTTP are not affected by its license. If you modify ramzes and let other people interact with that modified version over a network (for example as a hosted service), the AGPL requires you to offer those users the complete source code of your modified version under the same license.

## Commercial license

A commercial license removes the AGPL obligations, including the source-offering requirement for modified versions run as a network service.

## Contributions

Outside contributions are not being merged yet. A Contributor License Agreement will be set up first, so that the project can offer the code under both the AGPL and a commercial license.
